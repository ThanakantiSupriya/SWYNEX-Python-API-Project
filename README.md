# SWYNEX Python API Project — Public API Explorer

## About the Project

Public API Explorer is a Python web application built using Flask. It allows users to enter a post ID and retrieve post details from a public API.

## Features

* Fetches post data using a post ID.
* Validates user input.
* Displays post details on the web page.
* Handles invalid input and API errors.
* Provides a simple and user-friendly interface.

## Technologies Used

* Python
* Flask
* Requests Library
* HTML
* JSONPlaceholder Public API

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/ThanakantiSupriya/SWYNEX-Python-API-Project.git
```

### 2. Navigate to the Project Folder

```bash
cd SWYNEX-Python-API-Project
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install Required Libraries

```bash
pip install flask requests
```

### 6. Run the Application

```bash
python app.py
```

Open your browser and visit:
`http://127.0.0.1:5000/`

## API Used

JSONPlaceholder — `https://jsonplaceholder.typicode.com/posts/1`
